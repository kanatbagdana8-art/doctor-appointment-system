# doctor-appointment-system
Дәрігерге жазылу жүйесі
## Жоба туралы

*Дәрігерге жазылу жүйесі* — пациенттерге дәрігерлер туралы ақпаратты қарап, қолайлы қабылдау уақытын таңдап, онлайн жазылуға мүмкіндік беретін веб-қосымша.

## Жобаның мақсаты

Медициналық қызметтерге қолжетімділікті жеңілдету, пациенттердің уақытын үнемдеу және дәрігерлердің қабылдау кестесін тиімді басқару.

## Негізгі мүмкіндіктері

- Пациентті тіркеу және жүйеге кіру.
- Дәрігерлер мен олардың мамандықтарын қарау.
- Дәрігерлерді іздеу және сүзгілеу.
- Қабылдау уақытын таңдау.
- Дәрігерге онлайн жазылу.
- Жазылуларды қарау және болдырмау.
- Дәрігердің жұмыс кестесін басқару.
- Әкімші панелі арқылы жүйе ақпаратын басқару.

## Пайдаланушылардың рөлдері

1. *Пациент* — дәрігерлерді қарайды және қабылдауға жазылады.
2. *Дәрігер* — жұмыс кестесі мен қабылдауларын басқарады.
3. *Әкімші* — дәрігерлер, мамандықтар және пайдаланушылар туралы ақпаратты басқарады.

## Жобаның негізгі беттері

1. Басты бет
2. Тіркелу беті
3. Жүйеге кіру беті
4. Дәрігерлер тізімі
5. Дәрігер профилі
6. Қабылдауға жазылу беті
7. Менің жазылуларым
8. Жеке кабинет
9. Дәрігер кабинеті
10. Әкімші панелі

## Дерекқор құрылымы

Жоба келесі негізгі кестелерді қамтиды:

- users — пайдаланушылар туралы ақпарат.
- specialties — дәрігер мамандықтары.
- doctors — дәрігерлер туралы мәліметтер.
- schedules — дәрігерлердің қабылдау кестесі.
- appointments — пациенттердің жазылулары.

## Қолданылатын технологиялар

Жобаны іске асыру үшін ұсынылатын технологиялар:

- *Frontend:* HTML, CSS, JavaScript.
- *Backend:* Python және Flask.
- *Database:* SQLite.
- *Version control:* Git және GitHub.

# 9-апта бойынша есеп
## Тақырыбы: Дәрігерге жазылу жүйесі

Осы аптада «MedBook — Дәрігерге онлайн жазылу жүйесі» веб-қосымшасының frontend бөлігін әзірлеу жұмыстары орындалды.

Жобаның пайдаланушы интерфейсін жасау үшін HTML, CSS және JavaScript технологиялары қолданылды.

Орындалған жұмыстар:
1. Веб-қосымшаның басты бетінің құрылымы жасалды.
2. Пайдаланушыны тіркеу және жүйеге кіру беттерінің макеттері әзірленді.
3. Дәрігерлер тізімі көрсетілетін бет жасалды.
4. CSS көмегімен интерфейстің дизайны безендірілді.
5. Адаптивті дизайн іске асырылды.
6. Беттер арасында навигациялық байланыс орнатылды.
7. JavaScript көмегімен формаларды тексеру элементтері қосылды.

Нәтижесінде дәрігерге онлайн жазылу жүйесінің негізгі статикалық беттері әзірленді. Келесі кезеңде PHP және MySQL көмегімен дерекқормен байланыс орнату және жүйенің функционалдық мүмкіндіктерін іске асыру жоспарланды.
